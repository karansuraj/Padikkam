# Landscape research (Nov 2026)

No open source project found that combines a Malayalam script trainer, spaced repetition and AI conversation practice. The search was web search plus GitHub repository search, so it is not exhaustive.

## Reusable or related
- SMC mlmash (https://gitlab.com/smc/mlmash): web app for learning to write Malayalam, MIT. Best reference for the script trainer.
- Olam English-Malayalam dataset (https://olam.in/open/enml/): 200k+ entries, ODbL (attribution and share-alike apply). Check terms before bundling.
- Artham: MIT offline English-Malayalam dictionary for Android, built on Olam.
- naushada/learn-malayalam: 8-week spoken Malayalam plan with a phrase CSV. No license, inspiration only. Its README warns spellings are approximate.
- wslider/malayalam-explorer: about 320 flashcards in a Node app. No license, stalled.
- arxhr007/neurolearn: AI tutor for school curriculum, proprietary license, not a fit.

## Speech
- Sarvam offers Malayalam speech-to-text (about 1.25 rupees per minute with a free trial at time of research, verify current pricing) and claims code-switching support.
- Google Cloud TTS and Azure have ml-IN voices. Whisper is weak on Malayalam.

## Models
- MalayaLLM (Llama-2 7B) and abhinand/malayalam-llama-7b-instruct (GPL-3.0) exist but are small and skew formal. Not the foundation.

## Closed apps (for comparison)
Ling, Alphabing ML, Learn Malayalam Script. None are open source.
